# RIGR with molecule level charge featurizer

This branch is used to train all the models using RIGR for the property prediction benchmarks (except RGD1). The code is the same as [rigr](https://github.com/akshatzalte/chemprop/tree/rigr) but with an additional molecule level charge descriptor.

For more details, visit RIGR's [user information page](https://github.com/akshatzalte/chemprop/tree/rigr_home).

Reference:  [Resonance Invariant Graph Representation (RIGR) for Molecular Property Prediction]()
