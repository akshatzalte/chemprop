# RIGR with molecule level charge featurizer

This branch is used to train all the models using RIGR for the property prediction benchmarks (except RGD1). The code is same as [rigr](https://github.com/akshatzalte/chemprop/tree/rigr) but with additonal molecule level charge descriptor.

See [rigr_home](https://github.com/akshatzalte/chemprop/tree/rigr_home) for more information.

Reference:  [Resonance Invariant Graph Representation (RIGR) for Molecular Property Prediction]()
